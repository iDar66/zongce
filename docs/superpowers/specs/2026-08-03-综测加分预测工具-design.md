# 综测加分预测与总分核算工具 — 设计文档

> 状态：已与用户对齐（v2，扩范围至总分+奖学金），待审阅
> 日期：2026-08-03
> 依据：《广东技术师范大学学生综合测评实施办法》广师大〔2019〕509号（学生手册）+ 《2025-2026学年非毕业班计科院综测细则（7.15修改版）》+ 附件1《学科竞赛分类表》/《专项奖学金办法》
> 参考样例：`D:\综测证明材料\邓达俊2025-2026综测加分与奖学金预估.xlsx`（用户手工搭建的目标模板）

---

## 1. 背景与目标

每学期综测季，同学需要把一批活动/任职/获奖证明整理成 品德/学业/文体 三板块加分项，套公式算综测总分，再对照门槛和规则估可申请的奖学金——全手工、繁琐易错。

本工具把**可自动化的部分**自动化：给定姓名 + 一批证明 PDF + 少量手填输入（成绩/体测/志愿等），自动找出该同学的证明、归三板块、按加分模式预测加分，套官方公式算**综测总分**，并预估**可申请奖学金 + 硬性门槛**，产出一份邓达俊式的 Excel。

**目标产出**：`综测加分明细` + `总分与奖学金` 两张表的 Excel；外加物理归好类的 品德/学业/文体 三个文件夹。

**定位**：预测/预估工具，结果供核对参考，**不替代官方综测系统**。

## 2. 用户与使用场景

- **用户**：任意同学，本地运行。
- **场景**：浏览器里输入姓名 + 上传一批证明 PDF + 在表单填成绩/体测/志愿等 → 工具筛出含自己名字的文件、分类估分、算总分、估奖学金 → 导出 xlsx + 归好类的文件夹。
- **隐私**：全本地，文件不出本机，不联网、不调云 API。

## 3. 核心功能与产出

1. **按名字找文件**：从一堆 PDF 筛出提到指定姓名的（文字层 + OCR + 模糊匹配容错）。
2. **按三板块分类 + 加分预测**：归到 品德/学业/文体，按加分模式预测每个文件加分。
3. **算综测总分**：活动加分（自动）+ 表单输入（成绩等）→ 评分引擎套官方公式（德×0.2+智×0.65+体×0.15）出总分。
4. **奖学金预估 + 门槛**：硬性门槛检查 + 可申请奖学金（把握度）+ 互斥规则。
5. **产出**：邓达俊式 xlsx（两张表）+ 物理归类的 3 个文件夹。

## 4. 技术栈

全本地，环境均已具备：**Streamlit**（界面+表单）、**PyMuPDF**（PDF文字层+坐标）、**RapidOCR**（扫描件OCR）、**rapidfuzz**（姓名模糊匹配）、**pandas+openpyxl**（Excel导出）。

## 6. 模块划分

| 模块 | 职责 | 依赖 |
|---|---|---|
| `extract.py` | PDF→文字（文字层优先，OCR兜底，保留坐标，带缓存） | pymupdf, rapidocr |
| `name_match.py` | 姓名模糊匹配 + 上下文片段 + 姓名↔次数坐标配对 | rapidfuzz |
| `classify.py` | 加分模式识别 + 关键词分类（返回板块+模式） | rules.py |
| `predict.py` | 组装单文件预测（板块/模式/分值/次数/依据/备注） | classify, name_match |
| `scoring.py` | **评分引擎**：基本分 + 附加折算 + 合成公式 → 模块分+总分 | rules.py |
| `scholarship.py` | **奖学金预估**：门槛检查 + 可申请奖项 + 互斥 | rules.py |
| `forms.py` | **表单输入**：成绩/体测/志愿/班最高/认定/手动加分项 | streamlit |
| `rules.py` | 加分模式规则 + 关键词→板块 + 基本分/折算/合成公式 + 奖学金/门槛规则（**纯配置**） | — |
| `export.py` | 导出邓达俊式 xlsx；按板块物理复制文件 | pandas, openpyxl |
| `app.py` | Streamlit 界面 + 串联各步 + 手动修正 | 全部 |

`rules.py` 为纯配置：细则每年改、活动名会变、奖学金办法会更新，规则与代码分离。

## 7. 加分模式识别器（PDF 自动估分核心）

对每个命中文件读其加分陈述，识别为四种模式之一：

| 模式 | 触发特征 | 预测分计算 | 自动? |
|---|---|---|---|
| **① 次数型** | 有「每次/次数」+ 数值 + 姓名旁的 `(N)` | 单次值 × N | ✅ |
| **② 固定值型** | 有数值、无次数语义 | = 该数值 | ✅ |
| **③ 获奖分级型** | 涉及名次/等级（一等/前三/冠军…） | 抽【赛事级别+名次】查细则表；不全→待确认 | ⚠️ 多数待确认 |
| **④ 细则参照型** | 「按综测细则…加分」、无数值 | 待确认，依据附证明原文+细则条款 | ❌ 待确认 |

**原则**：能算就算，算不了标「待手动确认」，但每行保留 板块/依据/备注。

**次数型技术风险（坐标重建表格）**：「姓名｜班级｜次数」多栏排版，用 PyMuPDF `get_text("dict")` 坐标（OCR 用 bbox）按位置聚类还原行列配对。失败→次数默认1，备注标注。

**经验数据（李同学27个活动证明）**：次数型10 / 固定值型15 / 获奖分级型2 / 细则参照型0。

## 8. 关键词分类（兜底）

自带规则解析不到时，用 `rules.py` 关键词表匹配文件名+内容定板块：
- **品德**：干部/主席/部长/干事/后勤/工作人员/社会实践/三下乡/表彰/文明宿舍/志愿…
- **学业**：竞赛/挑战杯/数学建模/ACM/论文/专利/证书/四六级/创新项目/普通话/教资…
- **文体**：运动会/篮球/足球/排球/乒乓球/羽毛球/跳绳/定向/文艺/演出/歌唱/主持/辩论/裁判…
- 唯一命中→该板块；零命中或多类命中→「待确认」下拉框手选。

## 9. 评分引擎（总分核心）

依据手册+细则，每模块先算成百分制，再按手册第二条加权合成：

| 模块 | 基本分 | 附加分 | 条款 |
|---|---|---|---|
| **品德** | 70 | 品德附加raw（干部/后勤/实践/表彰…，部分有封顶如后勤≤10） | 手册第六条 + 细则第二章 |
| **学业** | 加权平均分 × 0.8 | 学业附加raw（竞赛/证书/四六级/单科/创新）**折算**：raw/班最高×20，封顶20 | 手册第十/十一条 + 细则第三章 |
| **文体** | 60 | 文体附加raw（体育/文艺/裁判）**折算**：raw/班最高×40，封顶40 | 手册第十四条 + 细则第四章 |

> 单科加分：≥90每科+1、85-89每科+0.5（细则第十一条.8），计入学业附加raw。
> **总分 = 品德×0.20 + 学业×0.65 + 文体×0.15**（手册第二条：20%/65%/15%，德智体先各按百分计再加权）。
> 附加折算依赖「班级最高raw」（班级统计），表单手填或按保守/中位/乐观三档估（对齐邓达俊表做法）。
> 各模块满分 100（手册第二条：德、智、体先各按一百分计，再加权合成）。

**实现时核实项**：基本分系数（70 / ×0.8 / 60）、各封顶值、折算公式需逐条对照手册/细则原文确认后录入 `rules.py`；另需核实**单科加分是否计入折算 raw**（邓达俊表按"计入 raw 后一起折算"处理，实现时对照手册第十一条确认）。

## 10. 输入表单（非 PDF 输入）

在 Streamlit 内置表单手填（对齐邓达俊表里手填的那些）：
- 加权平均分；单科成绩列表（或直接给 ≥90 门数 + 85-89 门数）
- 体测分；志愿时长
- 班级最高raw（学业/文体，或选"我就是班最高"）
- 认定状态项（如数模级别：省B/国/不认）
- 手动加分项（任职/证书/PDF里没有的，自由填板块+分值+依据）

## 11. 奖学金预估 + 门槛（`scholarship.py`）

依据 **附件6《本科生奖学金管理办法（2023修订）》**（已读）+ 手册 + 细则：

**奖学金种类与金额/比例**（第三/十二/十三条）：
- **优秀学生奖学金**：优秀三好（1%，**3000元**）/ 三好（6%，**2000元**）/ 优秀学生干部（4%，**800元**）/ 综合测评单项（班级15%，**500元**）
- **学校专项**：优秀学术成果（特2000/一1000/二500/三200）；竞赛专项（学术科技、文艺体育，按**国家级基准**，世界级×3、省级×1/2、市级×1/4，组队2-4人按(人数+1)/2倍、5人+按3倍总额）；工作积极分子（2%，**无奖金**）
- **其他**：国家奖学金 / 国家励志 / 单位(个人)专项 / 自强标兵（各自实施细则，金额/条件另查）

**互斥/兼得**（第十五/十六/十七条）：
- 第十七条：优秀三好、三好、优秀学生干部、综合测评单项、工作积极分子 **五项不得重复享受**（即邓达俊表①组）。
- 第十六条：国奖/国励 与 优秀学生奖学金 荣誉可兼得，但原则上不重复发钱。
- 第十五条：优秀学术成果专项 + 其他专项，同一项目不重复，按最高额。

**硬性门槛**（第十八条，不达标即取消优秀学生奖学金/工作积极分子资格）：受通报批评/纪律处分；因病缺课≥4周或旷课≥5节或事假>5天；任一课程不及格(绩点0)；德智体原始分<60；新生手册考试不及格。（另：体测、志愿时长等门槛来自综测细则，一并检查。）

**把握度估算的诚实边界**：三好/优秀三好/国奖等要看**班级/学院排名**与名额比例（1%/6%…），个人不一定知道精确排名——故把握度按"已知条件达标情况 + 排名未知"给保守/中位/乐观三档，并把"待班级排名确定"列入待认定清单（对齐邓达俊表做法），不假装能精确判定。

**实现时核实项**：三好/优秀三好具体排名阈值（如综测前25%、德智体前X%）来自《优秀学生奖学金、学校专项奖学金实施细则》（另一份文档，需另查录入）；国奖/国励金额与条件按各自细则。

## 12. 输出规格

### 12.1 Excel 两张表（邓达俊式）

**表1 `综测加分明细`**：`类别 | 项目 | 级别/明细 | 细则依据 | 加分 | 认定状态 | 备注`，分 品德/学业/文体 三段，各段末出模块小计（如「▶ 品德分 70+附加 82~87」）。

**表2 `总分与奖学金`**：保守/中位/乐观三档总分（品德/智育/文体/综测总分）+ 硬性门槛清单 + 可申请奖学金（金额/把握度/条件/互斥）+ 互斥规则 + 待认定清单。

界面内表格可编辑（改板块/分值/认定状态），编辑后再导出。

### 12.2 物理文件夹

用户指定输出目录下建 `品德/ 学业/ 文体/`，按板块复制命中文件（重名加序号）；「待确认」入 `待确认/`。默认输出目录：输入文件同级下以姓名命名的子文件夹。

## 13. 错误处理与边界

| 情况 | 处理 |
|---|---|
| OCR 姓名识错 | rapidfuzz 模糊匹配（≥0.8）+ 界面上下文勾选确认 |
| 姓名↔次数配对失败 | 次数默认1，备注标注 |
| 加分模式+关键词都失败 | 板块「待确认」→ `待确认/`，预测分留空 |
| 获奖分级抽不全 | 预测分「待确认」，依据附细则条款 |
| 同班重名 | 备注「疑似重名，请核对班级」（固有局限） |
| 附加折算缺班最高raw | 按保守/中位/乐观三档出区间，标注 |
| 非 PDF（docx/xls/图片） | MVP 只吃 PDF，其余跳过并提示 |
| 重跑 | 按文件内容 hash 缓存抽取，不重复 OCR |

## 14. 测试策略

- **单元**：`classify`（四模式样本）/ `name_match`（模糊+次数配对）/ `scoring`（基本分+折算+合成，构造已知输入断言总分）/ `scholarship`（门槛判定+互斥）。
- **端到端基准**：以邓达俊为黄金用例——喂其活动 PDF + 已知手填输入，断言输出对齐 `邓达俊…xlsx` 的总分与奖学金结论。
- **活动抽取回归**：用 `D:\综测证明材料` 内的活动证明批次（如 `大一/`）跑全流程，断言按姓名筛出/分类/估分正确（李同学 `2.zip` 是更早一次性任务的产物，不计入项目 fixtures）。
- **手工抽检**：随机扫描件人工核对。

## 15. 分阶段交付

- **P1（活动自动+预测表）**：抽取/姓名筛选/分类/加分模式识别 → 出 `综测加分明细`（仅活动加分）+ 3 文件夹。**先跳通 PDF 自动这条主线。**
- **P2（表单+评分引擎→总分）**：表单输入 + `scoring.py` → 出三模块分 + 总分，`总分与奖学金` 表先放总分档。
- **P3（奖学金+门槛）**：`scholarship.py` 完善可申请奖项/互斥/门槛，`总分与奖学金` 表补全。

每阶段独立可验证，P1 即可单独用（当加分预测表用）。

## 16. 范围边界（不做什么）

- ❌ 不替代官方综测系统，结果仅供核对。
- ❌ 不联网、不调云 LLM/API（路线A：纯规则+解析，本地确定）。
- ❌ MVP 不处理非 PDF 文件。
- ❌ 不做 OCR 之外的图像理解（表格靠坐标重建）。
- ❌ 不自动获取班级最高raw / 成绩单（需手填；成绩单若日后有可解析文件再扩展）。

## 17. 设计决策记录

- **路线A（规则+解析）**：与"本地、隐私、稳、确定"取向一致，活动证明自带规则已验证可行。
- **加分模式识别器（4模式）**：用户指出"次数×单次"不通用（有"按综测细则实际"写法），升级为多模式，算不了标待确认。
- **扩范围至总分+奖学金**：用户指出 `D:\综测证明材料` 有完整依据（手册公式20/65/15 + 细则 + 附件1）和手工样例（邓达俊xlsx），总分可算；故从"只出加分预测"扩到"总分+奖学金"，混合模式（PDF自动+表单手填+评分引擎）。
- **权重已核实**：手册第二条原文确认 20%/65%/15%，德智体先各按百分计再加权。
- **物理3文件夹**：用户要求物理复制（非仅逻辑归类）。
- **分阶段**：P1先交付活动自动+预测表（即原设计），P2/P3 再叠加总分与奖学金，降低一次性复杂度。
