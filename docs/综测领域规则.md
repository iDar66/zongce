# 广师大综测与专项奖学金领域规则

> **来源**：2025-2026 学年细则 + 手册第十条 + 《附件6：专项奖学金实施细则解释.docx》。**学院每年 7 月修订**，用前务必让用户确认用的是**当学年新版**（数字/比例可能微调）。原始材料在 `D:\综测证明材料\`。
>
> 本文是 P2（评分引擎/总分）与 P3（奖学金/门槛）的事实依据。P1 只做活动加分预测，不含本文的折算/门槛逻辑。

## 一、综测总分口径（P2 用）

- **总分 = 品德×20% + 学业×65% + 文体×15%**。各项先按 100 分制（可超 100），再按权重计入。
- **基本分**：品德 70、文体 60；**学业 = (Σ成绩×学分 / Σ学分) × 0.8**（手册第十条）。
- **附加分封顶折算**：学业附加 ≤ 20、文体附加 ≤ 40。当班级最高 raw 超上限时，按 `个人 raw / 班最高 raw × 上限` 折算；不超则直接计。⚠️ P1 的 `综测加分明细.xlsx` 只给 raw 附加分，**不含 70 基本分、不含折算**——这俩在 P2。
- **文体参与分按"场"不是按"赛事"**：校级球类每场 +2（封顶 20）、院级每场 +1（封顶 10）；名次分（获奖另加）单独算、不占参与分额度；裁判 0.5/场。

### 计算时需用户确认的变量
当学年新版细则数字、干部职务、全勤、证书、数模认定级别、**班级最高附加分**（折算分母）。

## 二、综测认定坑（影响加分口径）

- **证书印"国家级" ≠ 学校认定国家级**。学校只认《学科竞赛分类表》白名单 + 主办方级别。例：五一数模主办是江苏省工业与应用数学学会（省一级学会）→ 按分类表大概率算**省级 B 类**，非国家级。
- **跨校外校的大创立项不计入本校综测**（如广州商学院推荐的国家级大创，成员是广师大学生也不算）。
- **团学干部做本组织常规工作不另加后勤分**（体育部干事保障本院赛事 = 本职）；但辅导员**盖章认定的后勤综测证明倾向计入**——申报时全列上。
- 校级优秀学生奖学金（优秀三好/三好/优秀学生干部/单项/工作积极分子）**互斥只能拿一项**；国家奖/国家励志/专项奖学金可与上述**叠加**。
- **国家奖学金/国家励志要求志愿 ≥ 15h**（校级评优只要 ≥ 5h），且需**大二以上**、凭上一学年成绩申报；国家励志另需家庭经济困难认定。

## 三、专项奖学金（P3 用）

**体系**：专项奖学金是大类，下设子类 —— ①**普通奖学金**（学科竞赛获奖类，含数学建模）②**论文奖学金**（须被数据库收录，仅第一/通讯作者）③体育类（统一由体育与健康学院推荐）④文艺类。所以「普通奖学金 ⊂ 专项奖学金」。原始材料：`D:\综测证明材料\附件1：专项奖学金\`。

### 普通奖学金（竞赛类）4 道硬门槛（须同时满足）
1. **主办方须为政府部门或行业协（学）会**；公司/企业主办不行（反例：全国大学生信息技术认证挑战赛、英语世界杯、空英杯）。
2. **获奖比例 ≤ 50%**（含 50%，不含优秀奖）—— 自行算 `(特等+一等+二等+三等) / 参赛总数`，需官网公示链接 + 截图。**这是生死线，不看获奖等级**。
3. 由学校相关部门或学院**统一组织参赛** + 比赛资料在**学生工作部（处）备案**；个人自行参赛不算。
4. 在奖学金申报时间范围内。

**降一级**：政府下级单位 / 行业协（学）会主办的比赛按降一级定级奖励额（影响钱，不影响能否申）。文件**点名五一数模、泰迪杯**。

**蓝桥杯式踩线**：若省赛获奖比例 > 50%，则省赛获奖不可申请，**须国赛荣誉**才行。

### 五一数模天然过门槛（每届复用，不必重算）
章程规定一/二/三等奖分别**不超过**报名队数 5%/15%/25%，合计上限 **45% < 50%** → 每届天然满足获奖比例门槛。不设特等奖，分子 = (一等+二等+三等)。第23届(2026)实测：5307 队 / 261+729+1215=2205 → 41.5%（官网 51mcm.cumt.edu.cn，每年 6 月中旬发）。申报：截「评选结果公示」页 + 贴算式 `(261+729+1215)/5307≈41.5%≤50%`。

### 奖金标准（学术科技类，管理办法第13条第2款）
- 国家级：特等 3000 / 一等 2000 / 二等 1500 / **三等 800**（元/人）。
- **级别折算**：世界级 = 国×3，**省级 = 国×1/2**，市级 = 国×1/4。
- **组队系数**：2-4 人队总额 = 个人额×(人数+1)/2；5 人及以上 = 个人额×3。
  ⇒ 推算：省级三等 3 人队 = 800×0.5×(3+1)/2 = **800 元总额**（人均约 267）。
- **定级流程**：先按分类表定级 → "行业协(学)会主办"再降一级。序列：国A > 国B > 省A > 省B > 校C。
- **五一数模定级变数**：省一级学会 → 命中省B → 被点名降一级 = **校C**，而专项奖学金只覆盖国际/国/省/市四级、**无校级标准** → 最坏降校C 则拿不到专项奖金（**综测加分不受影响**）。最终能否拿钱取决于学校怎么认定"降一级"，**申报前必须问辅导员/学生处**。

### 不列入专项奖学金
互联网+、挑战杯、创青春（另按广师大〔2019〕119 号办法奖励）。

### 其他坑
- 联合培养班：奖状必须写「广东技术师范大学」，写深信息/广科院的不能申。
- 团队含外校成员：外校姓名不能写进本校申请表；全为本校的，只能由其中一人在其所在学院申请（**不可重复申请**）。
- 论文奖学金证明：稿件录用证明 + 期刊封面 + 目录 + 正文 + 数据库收录链接 / 网络首发链接。
